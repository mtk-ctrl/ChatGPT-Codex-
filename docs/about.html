Codex・Workのリセットカレンダーと独自予測

ChatGPT Work・Codexの利用枠に関する臨時リセットをカレンダーで確認できます。公式の日付はそのまま表示し、時刻付き記録は日本時間に換算します。一次資料の蓄積から独自予測も試みます。

履歴一覧リセットの種類予測の計算方法出典について

出典について

OpenAIの一次資料だけを使う非公式サイトです。

このサイトについて

ChatGPT Work・Codexの臨時リセットを記録しています。OpenAIとは関係ありません。運営：mtk-ctrl。

情報源

OpenAI公式ヘルプなどのOpenAI公式サイトと、OpenAI関係者本人のX原投稿のみを掲載します。X原投稿は内容を確認できた範囲を区別し、元投稿URLだけでは掲載しません。

確認状況

OpenAI公式記事
OpenAI公式本文から直接確認した事実です。
OpenAI関係者のX原投稿
掲載URLは本人のX原投稿です。投稿ページを直接取得できない場合、検索エンジンに登録されたそのX原投稿の本文抜粋を照合しています。全文を確認したという意味ではなく、原投稿が更新・削除された場合の検出は保証できません。実施予告と完了報告を区別します。

日時の表記

公式発表に日付しかない場合、その記載日付をそのまま表示し、時刻は未公表とします。米国日付を根拠なく日本時間へ変換しません。X投稿時刻はリセット実施時刻ではありません。

更新の方法と限界

GitHub Actionsから2時間おきにOpenAI公式ヘルプとX公開プロフィールの直接確認を試みます。Xの閲覧制限や仕様変更によって取得できない場合は確認状況を表示します。全件網羅を保証しません。

独自予測

日時を確認した一次資料のみで計算します。十分なデータがない場合は予測を表示しません。OpenAI公式の予告ではありません。計算方法をご覧ください。

連絡先

GitHub Issuesで訂正をご連絡ください。

プライバシー

独自のアクセス解析・広告・Cookie・会員登録を設けていません。
