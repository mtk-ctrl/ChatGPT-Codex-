# 40｜訪問者計測・検索流入・秘密情報

更新日：2026-11-03。アクセス件数は現場で実取得した期間だけ報告し、取れなかった件数を0と扱わない。

## 1. 訪問者計測の仕組み

公開サイトの docs/assets/counter.js は、画面表示のない計測スクリプト。対象ページを閲覧すると、条件を満たすブラウザからVercelの公開POSTへイベントを送る。

- 公開受信先：Vercelのプロジェクト reset-visit-ingest、API /api/collect。コードは counter-ingest/api/collect.mjs。
- ブラウザが送信する内容：イベントID、ブラウザ単位の訪問者ID、30分単位のセッションID、ページのパス、流入元ホスト名、端末区分、テストフラグ。
- 公開受信APIはサイトのOrigin制限、許可したパス、UUID、サイズなどを検査し、バックエンドの所有者限定ストレージへ転送。検索語・URLクエリ・氏名・メール・IPは保存データとして送らない。
- 計測は特定のGitHub Pagesサイト上でのみ有効。Do Not Track、Global Privacy Control、無効設定、既知のbot、ブラウザブロック等で送信されない場合がある。訪問者数は**厳密な人間の実人数ではなくブラウザ単位の概数**。
- 非表示計測なので、ページに「あなたは何人目」と表示する機能はない。

## 2. 管理者だけの集計取得

公開POSTと異なり、集計GETは一般公開しない。

- 集計コード：counter-ingest/api/stats.mjs。
- Vercel project ID：prj_Quq1MsTLnZfceEpy1gwtOIQ5vruy（識別用。これ自体は秘密トークンではない）。
- GET /api/stats?from=YYYY-MM-DD&to=YYYY-MM-DD は、Vercel Authenticationが有効な **previewデプロイのみ** で使用する。コード上も VERCEL_ENV が preview でなければ404にする。
- 認証済みの管理者がVercelのプレビューURLを確認し、日付（JST）を指定して取得する。プレビューURLはデプロイごとに変わり得る。公開サイトにプレビューURLを記載しない。
- 集計には pageviews（PV）、visitors（ブラウザ単位）、sessions（訪問回数）、日別、ページ別、流入元別がある。test=1は検証用アクセスだけを集計し、本番値に混ぜない。
- 日付は最大93日分の範囲指定。比較時はタイムゾーン・期間・データ遅延を揃える。
- 保存先は旧ChatGPT Sites環境の所有者限定サービス。認証トークンは Vercelの暗号化環境変数 COUNTER_STORE_TOKEN として production/preview に設定し、GitHubやAI会話に値を転載しない。

元の設計では、Sites専用接続ツールがある会話からしか統計を取得できなかった。2026年10月29日にVercelの認証付きpreview経由に修復して、別の環境でも正規のVercel管理者権限を通じて取得可能にした。

**他のAIに移行するとき**：GitHubのコードを読むことと、非公開DBの実データにアクセスできることは別。VercelやSites側で必要な正規アクセス権を所有者から付与してもらう。アクセス権がなくても静的サイトの更新は継続できるが、訪問者集計は取得不能と報告。認証回避のためにAPIを公開しない。

## 3. 確認すべきテスト

~~~sh
node --test tests/test_counter.mjs tests/test_stats.mjs
~~~

- productionの集計エンドポイントが404であること。
- preview側が認証で保護され、正規の認証利用者には集計だけが返ること。
- 日付の不正入力・過大な期間・許されないHTTPメソッドを拒否すること。
- 保存先の応答不正・503等を「アクセス0人」と読み替えないこと。
- 検証用PVが本番PVに混入していないこと。
- トークンや個人識別子がGitHubや公開HTMLに含まれていないこと。

2026/10/29には2026/10/28～29（日本時間）の本番実測として、PV13、訪問者5（ブラウザ単位）、セッション6を取得。テストPV4は別枠。この数字は**当時の期間だけ**を指し、現在の累計ではない。

## 4. Google検索からの流入

Google Search Consoleで見る「クリック数」「検索結果での表示回数」「掲載順位」「クリック率」は、サイト全体の訪問者数と異なる。

- 2026/10/20～29を対象に当時取得したSearch Consoleの暫定集計：**検索クリック15、検索表示63、CTR約23.8%、平均順位約8.35位**。
- クリック＝人ではない。Google検索以外からの直接訪問、SNS・ブックマーク流入などは含まれない。
- 過去の取得日から遅れて数字が修正される場合がある。最新数値の報告時はプロパティと日付範囲、暫定/確定を明示する。
- Google Search Consoleの接続がある場合はサイトプロパティ https://mtk-ctrl.github.io/ChatGPT-Codex-/ を使う。別のAIに接続権限がない場合は所有者による認証が必要。

## 5. 権限と移行時の落とし穴

| 権限/情報 | 保管先 | 他のAIへの移行方法 |
|---|---|---|
| サイトのコードと履歴 | GitHub公開リポジトリ | cloneして閲覧。編集・pushにはGitHubの権限が必要 |
| Pages公開 | GitHub Actions / Pages | 適切な書込・Actions権限を付与 |
| 非表示計測のAPI | Vercelプロジェクト | プロジェクトの管理権限を正式に付与 |
| Sites内の計測DB | 既存の所有者限定サービス | Vercel経由の集計取得、または所有者が正規の方法でエクスポート |
| COUNTER_STORE_TOKEN | Vercel暗号化環境変数 | **値をチャットに貼らない**。所有者が必要な環境へ設定 |
| Search Console | Googleのサイトプロパティ | 所有者権限による接続・共有 |
| AddnessのGoal | Addness | 任意の進捗資料。これがなくてもGitHubで運用を続ける |

GitHub Pagesの公開だけなら無料構成を維持できる設計。Vercelや接続アプリの料金体系は後から変更され得るため、有料プランへの変更は所有者の承認なく実施しない。

## 6. 認証変更・移行の際の安全策

- 最初に現行のデータ保全・読取りと公開サイトの稼働を確認。いきなり既存トークンやプロジェクトを削除しない。
- 集計が止まったら収集失敗と集計読取失敗を分離する。Search Consoleのクリック数で穴埋めしない。
- 本番収集APIは誰でも統計を読めるAPIに変えない。
- 新しい保存先へ移行する場合は、先に検証用データで重複集計・JST・拒否応答を試験。移行前後で日別PV等を突き合わせる。
- 計測DBの保存データをAIに直接渡す前に、漏えい・公開範囲を確認し、必要な集計値のみに限定する。
